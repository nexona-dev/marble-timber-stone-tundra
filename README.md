# 🚀 SellBizOnline — Premium Business Marketplace (Redesign Prototype)

A high-fidelity, front-end prototype for **SellBizOnline**, a global marketplace for buying and selling businesses, brands, and digital assets. 

This project was developed to transform an outdated layout into a premium, high-converting "fintech" aesthetic (inspired by platforms like Flippa and Empire Flippers).

## ✨ Key Features
*   **Fintech Dark Mode UI:** Deep slate and emerald theme designed to build instant trust with high-value buyers and sellers.
*   **Interactive Savings Calculator:** A custom JavaScript slider that dynamically calculates the savings compared to traditional broker fees.
*   **Fully Responsive:** Seamless experience across desktop, tablet, and mobile devices.
*   **Modern Typography:** Clean, accessible text hierarchy using *Plus Jakarta Sans* and *Inter*.
*   **High-Converting Layout:** Strategic placement of CTAs, clean listing cards, and direct messaging UI.

## 🛠️ Tech Stack
*   **HTML5:** Semantic structure.
*   **CSS3:** Custom properties (variables), Flexbox/Grid, and advanced dark mode styling.
*   **JavaScript:** Pure JS for the interactive calculator and UI animations.
